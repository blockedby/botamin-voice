# Skill Brief — Visual Composition (showcase video)

Source: `skills/visual_composition/SKILL.md` (alias: `visual_composition`, type: tools: designer, subtype: ui)

## What it does
Design and refine product-quality visual surfaces: composition against a brief, design-system continuity, responsive transformation, full set of UI states, meaningful motion, perceived performance.

## Who it is for
Product teams and developers building landing pages, onboarding, dashboards, forms.

## Inputs → Outputs
- Inputs: audience & usage scenario, purpose, primary task, required content/data/interactions/states, references, existing components, tokens, brand rules, viewport range, constraints.
- Outputs: a rendered, refined UI surface + design brief, chosen composition pattern, hierarchy/flow decisions, state & feedback behavior, responsive transformation, anti-patterns to avoid.

## Key steps (from Creation loop)
1. Read brief, references, existing components, design tokens.
2. Choose composition pattern matching content relationship and primary task.
3. Define hierarchy, reading order, grouping, actions, visual flow before decoration.
4. Define responsive transformations and important UI states before polishing the ideal desktop state.
5. Implement with existing primitives and semantic interaction patterns.
6. Render representative widths, states, realistic content while easy to change.
7. Fix obvious hierarchy/flow/content/state/responsive problems first.
8. Refine typography, spacing, imagery, motion, perceived performance.

## Value
Interface that guides a real person through a task; coherent design system; honest content; no invented claims; render-and-refine loop instead of abstract metrics.

## Example result
A coherent product screen: one visual starting point, clear hierarchy, full state set (loading/empty/error/success/disabled), responsive recomposition, reused tokens, factual copy.

## CTA
Apply the `visual_composition` skill to the next screen you build: start with the brief, check states and responsive transformation.

# Pinned Codex app-server protocol schemas

These JSON Schema bundles are generated by **`codex-cli 0.146.0`** with the experimental API surface enabled:

```bash
bun scripts/codex-generate-schemas.ts --check
```

The generator invokes `codex app-server generate-json-schema --experimental` in a temporary directory, verifies the installed CLI version, and compares SHA-256 digests with `protocol-version.json`. Use `--write` only in a dedicated pinned-CLI upgrade change.

Both the legacy envelope and v2 schema bundles are committed because app-server's bidirectional JSONL stream uses shared JSON-RPC envelopes plus v2 thread/turn/dynamic-tool payloads. The runtime adapter validates its narrow consumed surface and deterministic fake-process contract tests fail on missing or malformed required fields.

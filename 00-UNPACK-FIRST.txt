BOTAMIN VOICE AGENT — UNPACK FIRST
==================================

This ZIP is a technical specification and AI-agent handoff bundle. It is not yet
the implementation repository.

Linux / macOS:
  mkdir -p botamin-agent-work
  unzip botamin-voice-agent-agent-handoff-v0.2.zip -d botamin-agent-work
  cd botamin-agent-work/botamin-voice-agent-spec

Windows PowerShell:
  New-Item -ItemType Directory -Force botamin-agent-work | Out-Null
  Expand-Archive .\botamin-voice-agent-agent-handoff-v0.2.zip -DestinationPath .\botamin-agent-work -Force
  Set-Location .\botamin-agent-work\botamin-voice-agent-spec

Then open AGENT_START_HERE.md.

Optional integrity check after extraction:
  sha256sum -c CHECKSUMS.sha256

Package validation requires Python 3 and PyYAML:
  python3 -m pip install PyYAML
  python3 scripts/validate-spec.py

# Post-booking qualification

## Ownership and scope

Этот файл определяет только необязательное обогащение уже созданной внутренней брони.

## Preconditions

Начинай квалификацию, только если одновременно выполнено всё:

- server context содержит существующий `bookingId` и статус `booked`;
- успешное создание брони уже подтверждено пользователю;
- пользователь согласился ответить на дополнительные вопросы;
- `append_booking_qualification` присутствует в `allowedActions`.

Если хотя бы одного условия нет, не задавай квалификационный вопрос и не вызывай qualification tool.

## Question selection

Выбери не более пяти самых полезных неизвестных полей, но обычно остановись раньше:

- роль и зона ответственности;
- отрасль или размер компании;
- порядок объёма лидов;
- текущие каналы и процесс;
- CRM;
- основные боли;
- желаемый use case;
- timeline.

Задавай один основной вопрос за раз. Не повторяй известное и не требуй заполнить всё.

## Patch and stopping rules

- После содержательного ответа можно вызвать `append_booking_qualification` с partial patch для той же брони.
- Не добавляй поля, которых пользователь не сообщал и которые server context не подтверждает.
- При отказе, усталости, молчании, ошибке, timeout или disconnect прекрати квалификацию; существующая бронь остаётся `booked`.
- При частично собранных данных можно завершить со статусом partial или skipped согласно server policy.
- В конце кратко поблагодари и не предлагай создать бронь повторно.
